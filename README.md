## ✨ Features

- 🕹️ Classic Snake gameplay using an HTML5 `<canvas>` grid
- 🎵 Background music and sound effects using the **Web Audio API**
- ⌨️ Multiple controls: **Arrow Keys, WASD, swipe, and on-screen buttons**
- ⏸️ Pause and resume using the **Spacebar**
- 🏆 High score saved using `localStorage`
- 📱 Responsive design for desktop and mobile
- 🌗 Light and dark theme support
