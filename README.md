## ✨ Features
 
- 🕹️ Classic Snake gameplay on an HTML5 `<canvas>` grid
- 🎵 Background music & sound effects — generated live with the **Web Audio API** (no audio files needed)
- ⌨️ Multi-input controls: **arrow keys**, **WASD**, **swipe** (mobile), and on-screen **buttons**
- ⏸️ Pause / resume anytime with the spacebar
- 🏆 High score saved locally with `localStorage`
- 📱 Fully responsive — plays smoothly on desktop and mobile
- 🌗 Light/dark theme aware

## 🚀 Getting Started
 
No installation, no dependencies — just download and open.
 
```bash
git clone https://github.com/your-username/snake-game.git
cd snake-game
```
 
Then simply open `snake-game.html` in your browser, or double-click the file.
 
## 🎯 Controls
 
| Action | Input |
|---|---|
| Move | Arrow keys / `W` `A` `S` `D` / swipe / on-screen buttons |
| Pause / Resume | `Spacebar` |
| Toggle music | 🔊 button |
 
## 🛠️ Built With
 
- **HTML5** — canvas-based game board
- **CSS3** — responsive, theme-aware styling
- **Vanilla JavaScript** — game loop, collision detection, Web Audio API for sound
