# 🐍 Snake Game

A simple and responsive **Snake Game** built using **HTML, CSS, and JavaScript**.

## 🎮 Features

* 🐍 Classic Snake gameplay
* 🎯 Score and Best Score tracking
* 🔊 Background music and sound effects
* ⌨️ Arrow keys and WASD controls
* 📱 Swipe controls for mobile
* 🕹️ On-screen direction buttons
* ⏸️ Pause and resume functionality
* 💾 Best score saved using Local Storage
* 🌙 Responsive dark/light theme support

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Canvas API
* Web Audio API
* Local Storage

## ▶️ How to Play

1. Click **Start Game**.
2. Use **Arrow Keys** or **WASD** to move the snake.
3. On mobile, use the **swipe gestures** or direction buttons.
4. Eat the food to increase your score.
5. Avoid hitting the walls or yourself.
6. Press **Space** to pause the game.
